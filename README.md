# inf-system
Написал код который первым дело определяет в какой ОС он работает, а дальше выводит ряд параметров о системе и ПК.
В коде были задействованы 3 основные библиотеки которые выводят всю нужную нам инфу: psutil, os, platform. Самой нужной по факту является psutil, остальные были использованы для наглядности и обучения.
Все параметры выводим через словарь, в словаре были задействованы строковые методы (f"Привет, {name}"), также для наглядности, как можно сделать
В значение (values) словаря использовал функции, строковые методы и кортежи - для примера как можно делать
На 52 строке кода был задействован условный оператор if - elif, для наглядности как мы можем подстроить наш код для определенной операционной системы. однако, как и было сказано ранее, все функции в этих библиотеках являются мульти-операционными, по крайней мере для рассмотренных мной ОС - windows и linux
поэтому этот оператор можно было и не делать, а написать просто в значении psutil.disk_usage (где psutil - библиотека, а disk_usage - функция) - ("/") и он бы все равно вывел инфу и в windows и в linux, как это показано на 32 строке кода в закоменченном виде
также с 38 по 40 строки находится код, при помощи которого можно вывести инфу о сети, в закоменченном виде потому, что информации там слишком много) но вот так сделать можно
На 48-49 строках находится конструкция которая может вывести запущенные процессы на пк, работает она через цикл for который, как я понял, передает переменной process объекты, которые нам выдает функция psutil.process_iter(), а потом мы уже просто выводим составляющие этих объектов в наш словарь, однако почему у pid нет (), то-есть почему это не функция, а name это функция и все это мы берем у переменной process я так и не смог понять, хотя очень пытался! 
Все наши дополнения к словарю, которые у нас появились в условных операторах и циклах, мы просто также присваиваем (добавляем) к этому словарю (a), при помощи обычной конструкции a[ключ] = значение
Ну и соответственно самой последней командой является создание файла json, который создается автоматически при выполнении кода. Все значения мы добавляем в словарь как раз для этого (в основном для этого), что бы все это красиво и понятно в него записалось.
* также что бы наши библиотеки работали - их нужно скачать на пк, но не все (например os или platform являются предустановленными)! делается это просто - на linux можно просто написать в командную строку pip install название (например psutil), а вот windows этот pip не понимает и ему нужно писать py -m pip install название.
